# Soap Calculator, by The Bee Guy

- **iPhone, iPad and computers** (the web version): https://papaasot.github.io/bee-guy-soap-calculator/
  Open it in Safari and use Share > Add to Home Screen; it then works like an app, with no signal.
- **Android app**: https://github.com/PaPaASOT/bee-guy-soap-calculator/releases/download/app/BeeGuySoapCalculator.apk
  Download it, tap the file, and allow installing from that app when Android asks.

Saved recipes stay on your own device only.
